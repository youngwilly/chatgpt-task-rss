日期：2026年8月2日

这一周财报真正改变了市场的讨论方向。

7月29日，Microsoft公布季度业绩，Azure收入增长43%，高于市场预期。商业合同余额（RPO）达到6780亿美元，同比增长84%。公司预计2026自然年资本开支约1750亿美元，下一季度单季资本开支超过500亿美元，同时自由现金流19.6亿美元，高于市场预期。股价盘后上涨超过8%。Reuters+1

数据缺口

目前仍没有可靠公开数据支持以下几个判断：

  1. 各Hyperscaler自研ASIC占AI总算力的实际比例。

  2. HBM长期合同覆盖全球需求的比例。

  3. 企业Agent部署后的真实投资回报率。

  4. AI长期记忆存储的年度采购金额。

这些地方仍需要等待未来几季财报和供应链数据。

交易员版本

现在最值得研究的方向：

企业AI商业化、HBM、ASIC、电力基础设施。

现在最可能被低估的标的：

Microsoft、Broadcom、Micron Technology。

现在最拥挤、最需要小心的标的：

自由现金流仍明显承压的大型AI基础设施平台。市场已经开始用现金流而不是收入增速重新定价。Reuters+1

未来30天需要盯的催化剂：

Amazon、Apple后续财报，云厂商资本开支更新，HBM价格与交期变化。

未来90天需要盯的数据：

Azure增速是否维持40%以上，Copilot付费用户增长，HBM供需变化，企业AI预算增速。

当前最优交易结构：

继续配置拥有真实收入兑现能力的平台公司，同时维持HBM、ASIC和电力基础设施仓位，对高资本开支但现金流改善缓慢的平台保持估值纪律。

我会在什么情况下承认这个判断错了：

如果未来两个季度Azure和Google Cloud增速明显放缓，Copilot商业化停滞，HBM价格快速下跌，同时大型云厂商连续下调资本开支，那么当前关于AI进入收入兑现阶段的判断需要重新修正。

三个值得继续思考的问题：

  1. 微软已经证明AI可以带来收入，未来两年谁最有机会成为第二个完成收入兑现的平台，Alphabet、Amazon还是Oracle？

  2. 如果HBM供给在2027年开始明显释放，利润池会首先迁移到ASIC、高速网络还是企业级存储？

  3. 当市场从追逐CapEx转向追逐现金流，AI产业链里哪些公司有机会迎来估值体系切换？

AI投资转折点周报

AI投资转折点周报

日期：2026年7月26日

这一周最大的变化发生在资本市场。

Alphabet公布季度业绩后，把全年资本开支指引再次提高到 1950亿至2050亿美元。收入和Google Cloud增长都超过预期，但自由现金流首次转负，股价仍下跌超过6%。市场开始重新给AI基础设施估值，焦点已经从“谁投得最多”变成“什么时候赚钱”。Financial Times+1

Reuters统计的LSEG数据显示，微软、Alphabet、Amazon、Meta和Oracle到2027年的累计AI资本开支增量约5340亿美元，同期经营现金流增量约3400亿美元，相当于每新增1美元经营现金流，需要投入约1.57美元资本开支。Reuters

另一边，Meta没有踩刹车。

路易斯安那 Hyperion 数据中心已经扩大到5GW，投资超过500亿美元。内部计划仍维持2027年14GW算力目标，自研ASIC "Iris"按计划推进。Investing.com+1

所以这一周最大的变化不是需求减弱，而是市场开始区分：

  • 真正拥有利润池的公司

  • 只能分享收入增长、却承担巨大资本开支的公司
