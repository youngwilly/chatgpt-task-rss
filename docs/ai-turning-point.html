MU依然第一，但现在已经是“高置信度、赔率没有以前舒服”的资产。

MRVL我从上周第二降到第三。

原因来自它自己的财报。

NVIDIA给Memory做了一次非常强的交叉验证

NVIDIA Q2毛利率75%。

Q3预计74%。

Q4预计：

71%至72%。

公司把原因直接指向memory成本。英伟达

这个数字比供应链传言有价值得多，因为NVIDIA是整个AI硬件产业链里议价权最强的公司之一。

连它都开始出现明显毛利率压力，说明memory卖方市场已经相当极端。

而且现在出现了一个反馈：

AI GPU增加
→ HBM需求增加
→ DRAM晶圆向HBM迁移
→ Server DRAM变紧
→ 普通DRAM变紧
→ Memory价格上涨
→ AI服务器成本上涨
→ NVIDIA提价。

TrendForce 8月4日甚至说，DRAM紧张已经迫使NVIDIA评估降低Rubin Ultra的HBM配置，包括从原来的12 Hi HBM4E考虑8 Hi版本，CSP自己的下一代ASIC也在评估降低HBM容量。TrendForce

这点很要命。

Memory已经开始影响AI芯片架构设计。

SK hynix 8月27日又给了一个更长期的信号。

公司预计全球memory shortage可能持续到2030年，Indiana HBM4E封装厂预计2029年Q3才开始量产。公司同时批准到2031年投入54.3万亿韩元，约383亿美元。Reuters

这意味着新增供给响应非常慢。

所以MU现在的问题已经不太是基本面。

主要问题变成价格。

今年市场已经把它从传统周期股重新估成AI基础设施资产。Reuters

我不会追大阳线。

6至18个月仍然做多。

如果出现20%左右的估值回撤，但Server DRAM价格没有下降，我会更愿意加。

失效条件还是那个：

Server DRAM合同价连续两个季度下降。

GPU越来越多。

所以我继续把AI Network放第二。

而且相比Memory，这条线还有一个优势。

Memory涨价最终会刺激扩产，也会压制终端需求。

Network content增加更像架构变化。

ANET还是我更喜欢的大市值表达。

CRDO和ALAB提供更高弹性，但估值风险更高。

AI产业投资转折点报告

2026年8月23日
